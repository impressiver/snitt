# Snitt Contributor Licence Agreement

Thank you for contributing to Snitt. This agreement exists for one reason, and
it is worth stating plainly rather than burying: **Snitt is released under the
Mozilla Public License 2.0, and the project needs to be able to license the same
code differently in future** — for example to ship a Mac App Store build, whose
terms are incompatible with some open-source licences, or to offer a commercial
licence alongside the free one.

That is only possible if one party holds sufficient rights over the whole
codebase. Without this agreement, relicensing would require tracking down and
getting permission from every past contributor, which in practice means it never
happens.

**What this is not:** it is not a copyright assignment. You keep the copyright in
your contribution and remain free to use it anywhere else, for anything, with no
obligation to Snitt.
