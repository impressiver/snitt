# Code of conduct

Snitt uses the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
The full text is at that link rather than copied here, so it cannot drift out of
date in a file nobody re-reads.

The short version: be decent. Criticise code, not people. Assume the other
person is trying to help.

**Reports go to conduct@impressiver.com**, read by the maintainer. There is one
maintainer, so a report about the maintainer has nowhere neutral to go inside
this project. That is a real limitation and pretending otherwise would be worse
than saying it: if that is your situation, GitHub's own
[abuse reporting](https://github.com/contact/report-abuse) is the escalation
path that does not run through me.
